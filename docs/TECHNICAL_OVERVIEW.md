## 2. Trusted Computing Base (TCB)

To trust every soundness theorem (`¬ Solvable L s`) and solvability theorem (`Solvable L s`), a reviewer only needs to audit the core definitions in [`Sokoban/Defs.lean`](../Sokoban/Defs.lean):

- `Dir` and `step : Pos → Dir → Pos` on `Pos := Int × Int`.
- `Level := { isWall : Pos → Bool, isGoal : Pos → Bool }` and `State := { player : Pos, boxes : List Pos }`.
- `ValidState L s`: player not on a wall, player not on a box, no box on a wall, and `s.boxes.Nodup`.
- `Step L s₁ s₂`:
  - `walk d s hw hb`: moves `player` to `step s.player d` when not a wall and not in `s.boxes`.
  - `push d s hb hw hnb`: moves `player` onto box `b₀ := step s.player d` and replaces `b₀` with `dest := step b₀ d` via `moveBox` when `dest` is neither a wall nor occupied.
- `Reach L` (reflexive-transitive closure of `Step L`), `IsSolved L s` (`∀ b ∈ s.boxes, L.isGoal b = true`), and `Solvable L s` (`∃ s', Reach L s s' ∧ IsSolved L s'`).

Notice that `mem_moveBox` proves `b ∈ bs → (x ∈ moveBox bs b b' ↔ x = b' ∨ (x ∈ bs ∧ x ≠ b))` directly without assuming `bs.Nodup`, while `moveBox_nodup` preserves `s.boxes.Nodup` across `Step.push` because `step (step s.player d) d ∉ s.boxes`.

For external ASCII XSB inputs, `parseLevel` is intentionally permissive (defaulting missing players to `(0, 0)` and unknown characters to floor), whereas `parseLevelStrict` rejects empty boards, invalid characters, missing/multiple players, zero boxes, and mismatched box/goal counts.

## 3. Architecture & Proof Strategy

### 3.1 Pure-Core Finite Fixpoint Engine (`Sokoban/Fixpoint.lean`)
Without Mathlib's `Finset`, `Fintype`, or lattice libraries, finite reachability and fixed-point pruning are built directly over `List Pos` using two length-terminating combinators:

- **`iterFixedUp`**: grows a duplicate-free subset inside a `Nodup` `bound` (`playable`), terminating early as soon as `(f xs).length == xs.length`. `iterFixedUp_fixpoint` uses pigeonhole counting (`length_le_of_nodup_subset`, `eq_mem_of_nodup_subset_length_eq`) to prove exact membership fixpoint `∀ x, x ∈ f res ↔ x ∈ res` once `bound.length ≤ xs.length + fuel`.
- **`iterFixedDown`**: shrinks a `Nodup` initial set (`dedupPos s.boxes`), terminating early when `(f xs).length == xs.length`. `iterFixedDown_fixpoint` yields `∀ x, x ∈ f res ↔ x ∈ res` once `xs.length ≤ fuel`. (Note: this guarantees convergence to a fixed point satisfying `IsSuperFrozenSet`, without asserting an additional lattice-maximality theorem.)

Early length-equality termination is essential so that kernel reduction (`decide`, without `native_decide`) evaluates concrete levels in milliseconds.

### 3.2 Static Dead Squares & Box Tracking (`Sokoban/DeadSquares.lean`)
- `SingleBoxStep` / `SingleBoxReach` abstracts box motion ignoring all other boxes and allowing free player repositioning between abstract pushes.
- `reach_tracks_box` proves by induction on `Reach` that every box `b ∈ s.boxes` in a `ValidState` tracks forward to some `b' ∈ s'.boxes` with `SingleBoxReach L b b'`.
- `computeLiveSquares` runs `iterFixedUp` backward from `playable.filter L.isGoal`. Under `ClosedPlayable L playable` (checked via `isClosedPlayable`), `singleBoxReach_goal_mem_liveSquares` proves completeness with respect to single-box goal reachability (necessary for sound pruning, though not implying a real-player solution exists), yielding `deadSquareDeadlock_sound`.

### 3.3 Unified Reachability-Aware Freeze Deadlocks (`Sokoban/Freeze.lean`)
The centerpiece theorem is **`superFreeze_sound`** for `IsSuperFrozenSet L playable live p₀ F`:
Every `b ∈ F` and every `d : Dir` must satisfy at least one of:
1. `L.isWall (step b d) = true ∨ step b d ∈ F` (destination blocked by wall or frozen box),
2. `step b d ∉ live` (destination is a Simple Dead Square),
3. `L.isWall (step b d.opp) = true ∨ step b d.opp ∈ F` (pushing side blocked by wall or frozen box),
4. `¬ CanWalkAvoiding L F p₀ (step b d.opp)` (pushing side topologically cut off from `p₀` by `wall ∪ F`).

**Why the invariant goes through:**
Crucially, a super-frozen box *can* sometimes be legally pushed in Sokoban (e.g., on `exPlayerTrapBoard`, box `(2,2)` belongs to `computeSuperFrozen` yet `up, up` legally pushes it to `(2,1)` onto a Simple Dead Square). What `superFreeze_sound` proves by induction along any *hypothetical winning path* `Reach L s₁ s₂` ending in `IsSolved L s₂` is that:
- `ValidState L s₁`, `s₁.player ∈ playable`, `∀ b ∈ s₁.boxes, b ∈ playable`, `∀ b ∈ F, b ∈ s₁.boxes`, and `CanWalkAvoiding L F s₀.player s₁.player` hold along the path as long as no box in `F` is pushed;
- Walking or pushing a box `b₀ ∉ F` extends `CanWalkAvoiding L F s₀.player ·` via `canWalkAvoiding_snoc` because `s₁.player` only moves onto `b₀ ∉ F`;
- Pushing any `b₀ ∈ F` contradicts all 4 clauses against a *winning* continuation: (1) & (3) contradict `Step.push` + `ValidState`; (2) contradicts `reach_tracks_box` + `singleBoxReach_goal_mem_liveSquares` applied to `IsSolved L s₂`; (4) contradicts `CanWalkAvoiding L F s₀.player s₁.player` via `step_opp`.

**Executable Fixed Point (`computeSuperFrozen`):**
`superFreezeStep` recomputes `computeWalkable L playable F p₀` at every shrinking iteration and keeps boxes blocked in all 4 directions (`dirBlockedBool`). `computeSuperFrozen_isSuperFrozen` turns the resulting fixed point directly into `IsSuperFrozenSet`, yielding `superFreezeDeadlock_sound`, plus corollaries `classicFreezeDeadlock_sound` and `block2x2Deadlock_sound`.

### 3.4 Decoupled Solver & Standalone Certificate Verification (`Sokoban/Solver.lean`)
Rather than proving full functional correctness of a BFS queue implementation, we use **certifying search**:
- `solveBFS` performs deadlock-pruned BFS up to `StateEquiv` (equality of player position and box set membership).
- On `.solved moves`, `verifySolution_sound` verifies `applyMoves` in linear time.
- On `.unsolvable cert` (either `.initialDeadlock` or `.closedRegion visited`), `checkUnsolvableCert` is **self-contained**: it validates `checkBoardPremises L playable s₀` (`ValidState`, `playable.Nodup`, `ClosedPlayable`, player/box membership), `visited.all (fun s => isNodupPos s.boxes)`, and for `.closedRegion visited` checks that `visited` represents `s₀`, contains no solved state, and that every `execDir` successor of every state in `visited` either triggers `isSuperFreezeDeadlockWithLive` or maps into `visited` modulo `StateEquiv` ($O(|V|^2)$ membership checks in the worst case).
- `checkUnsolvableCert_sound` requires **no external premises** beyond `checkUnsolvableCert L playable s₀ cert = true`, and `verifySolveResult` dispatches both `.solved` and `.unsolvable` results.

### 3.5 Formal Heuristic Refutations (`Sokoban/Counterexamples.lean`)
Three plausible pruning mistakes are formalized and refuted constructively with `ValidState` + `heuristic = true` + `Solvable` + `isSuperFreezeDeadlock = false`:
1. `naiveDeadSquareFreeze_unsound`: checking `!live.contains` symmetrically on the *pushing* side `step b d.opp` fails on `##### / #@$.# / #####`.
2. `naiveCurrentReachFreeze_unsound`: checking `CanWalkAvoiding` against *all* current boxes `s.boxes` instead of `F` fails on `cex2Board` (6×6, 4-move solution).
3. `naiveGoalLock_unsound`: on `cex3Board` (8×4, 14-move solution), both permanently locking `*` on goal `(4,2)` (`lockGoalBoxesLevel`) and the weaker rule `StepNoOffGoalPush` (forbidding only pushes from a goal onto *non-goal floor*, since `(5,2)` is non-goal floor) render the board provably unsolvable.

### 3.6 Verified PI-Corral & Corral-Merging Pruning (`Sokoban/PICorral.lean`, `Sokoban/PICorralCounterexamples.lean`)
- **`ReachPushes L s₁ s₂ k`** tracks exact push counts alongside `Reach L`.
- **`IsPICorral L live s₀ C B`** packages the enclosure invariant `hC_encl` (`wall ∪ B`), non-goal obligation `hUnsolved`, dead-square-aware I-condition `hICorral` (stripping `s₀.boxes \ B`), and P-condition `hPCorral` (retaining `s₀.boxes`). Because `hC_encl` only constrains `C` via `wall ∪ B`, single corrals and arbitrarily merged multi-room corrals satisfy the exact same predicate.
- **`piCorral_push_optimal`**: splits any solved `k`-push trace at the first push `(b₀ ∈ B, d)` via `split_first_push_in_B` into a `B,C`-avoiding prefix (`ReachAvoidingBC`, length `k₁`) and suffix (`k₂`), shows `dest ∈ C` (`hICorral` + `reach_tracks_box` + `singleBoxReach_goal_mem_liveSquares`), walks from `b₀` back to `s₀.player` avoiding `moveBox s₀.boxes b₀ dest` (`canWalkAvoiding_symm` + `canWalkAvoiding_shifted`), replays the `k₁`-push prefix shifted by `moveBox_comm` (`replay_avoiding_shifted`), steps onto now-empty `b₀`, and finishes in `k₁ + k₂ = k - 1` pushes.
- **Executable Finder & Bug Refutations**: `isPICorralBool_sound` lifts Boolean checks to `IsPICorral` via `mem_computeWalkable_canWalkAvoiding`; `findPICorral` greedily merges neighboring corral components; and `PICorralCounterexamples.lean` refutes forgetting to strip external boxes in the I-check (`picex1Board`), stripping external boxes in the P-check (`picex2Board`), and omitting `hUnsolved` (`picex3Board`).
