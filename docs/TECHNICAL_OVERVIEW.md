## 2. Trusted Computing Base (TCB)

To trust every soundness theorem (`¬ Solvable L s`) and solvability theorem (`Solvable L s`), a reviewer only needs to audit ~90 lines of definitions in [`Sokoban/Defs.lean`](../Sokoban/Defs.lean):

- `Dir` and `step : Pos → Dir → Pos` on `Pos := Int × Int`.
- `Level := { isWall : Pos → Bool, isGoal : Pos → Bool }` and `State := { player : Pos, boxes : List Pos }`.
- `ValidState L s`: player not on a wall, player not on a box, no box on a wall.
- `Step L s₁ s₂`:
  - `walk d s hw hb`: moves `player` to `step s.player d` when not a wall and not in `s.boxes`.
  - `push d s hb hw hnb`: moves `player` onto box `b₀ := step s.player d` and replaces `b₀` with `dest := step b₀ d` via `moveBox` when `dest` is neither a wall nor occupied.
- `Reach L` (reflexive-transitive closure of `Step L`), `IsSolved L s` (`∀ b ∈ s.boxes, L.isGoal b = true`), and `Solvable L s` (`∃ s', Reach L s s' ∧ IsSolved L s'`).

Notice that `s.boxes` is an arbitrary `List Pos` (not even required to be `Nodup` in `ValidState`!). The key lemma `mem_moveBox` proves `x ∈ moveBox bs b b' ↔ x = b' ∨ (x ∈ bs ∧ x ≠ b)` without assuming `Nodup`, avoiding unnecessary invariants across state transitions.

## 3. Architecture & Proof Strategy

### 3.1 Pure-Core Finite Fixpoint Engine (`Sokoban/Fixpoint.lean`)
Without Mathlib's `Finset`, `Fintype`, or lattice libraries, finite reachability and greatest-fixed-point pruning are built directly over `List Pos` using two length-terminating combinators:

- **`iterFixedUp`**: grows a duplicate-free subset inside a `Nodup` `bound` (`playable`), terminating early as soon as `(f xs).length == xs.length`. `iterFixedUp_fixpoint` uses pigeonhole counting (`length_le_of_nodup_subset`, `eq_mem_of_nodup_subset_length_eq`) to prove exact set-equality `∀ x, x ∈ f res ↔ x ∈ res` once `bound.length ≤ xs.length + fuel`.
- **`iterFixedDown`**: shrinks a `Nodup` initial set (`dedupPos s.boxes`), terminating early when `(f xs).length == xs.length`. `iterFixedDown_fixpoint` yields `∀ x, x ∈ f res ↔ x ∈ res` once `xs.length ≤ fuel`.

Early length-equality termination is essential so that kernel reduction (`decide`, without `native_decide`) evaluates concrete levels in milliseconds.

### 3.2 Static Dead Squares & Box Tracking (`Sokoban/DeadSquares.lean`)
- `SingleBoxStep` / `SingleBoxReach` abstracts box motion ignoring all other boxes.
- `reach_tracks_box` proves by induction on `Reach` that every box `b ∈ s.boxes` in a `ValidState` tracks forward to some `b' ∈ s'.boxes` with `SingleBoxReach L b b'`.
- `computeLiveSquares` runs `iterFixedUp` backward from `playable.filter L.isGoal`. Under `ClosedPlayable L playable` (checked once per level via `isClosedPlayable`), `singleBoxReach_goal_mem_liveSquares` proves completeness of `computeLiveSquares` w.r.t. single-box goal reachability, yielding `deadSquareDeadlock_sound`.

### 3.3 Unified Reachability-Aware Freeze Deadlocks (`Sokoban/Freeze.lean`)
The centerpiece theorem is **`superFreeze_sound`** for `IsSuperFrozenSet L playable live p₀ F`:
Every `b ∈ F` and every `d : Dir` must satisfy at least one of:
1. `L.isWall (step b d) = true ∨ step b d ∈ F` (destination blocked by wall or frozen box),
2. `step b d ∉ live` (destination is a Simple Dead Square),
3. `L.isWall (step b d.opp) = true ∨ step b d.opp ∈ F` (pushing side blocked by wall or frozen box),
4. `¬ CanWalkAvoiding L F p₀ (step b d.opp)` (pushing side topologically cut off from `p₀` by `wall ∪ F`).

**Why the invariant goes through:**
Along any `Reach L s₁ s₂` starting from `s₀`:
- `ValidState L s₁`, `s₁.player ∈ playable`, `∀ b ∈ s₁.boxes, b ∈ playable`, `∀ b ∈ F, b ∈ s₁.boxes`, and `CanWalkAvoiding L F s₀.player s₁.player` are maintained simultaneously.
- Walking or pushing a box `b₀ ∉ F` extends `CanWalkAvoiding L F s₀.player ·` via `canWalkAvoiding_snoc` because `s₁.player` only moves onto `b₀ ∉ F`.
- Pushing any `b₀ ∈ F` contradicts all 4 clauses: (1) & (3) contradict `Step.push` + `ValidState`; (2) contradicts `reach_tracks_box` + `singleBoxReach_goal_mem_liveSquares`; (4) contradicts `CanWalkAvoiding L F s₀.player s₁.player` via `step_opp`.

**Executable Greatest Fixed Point (`computeSuperFrozen`):**
`superFreezeStep` recomputes `computeWalkable L playable F p₀` at every shrinking iteration and keeps boxes blocked in all 4 directions (`dirBlockedBool`). `computeSuperFrozen_isSuperFrozen` turns the fixpoint output directly into `IsSuperFrozenSet`, yielding `superFreezeDeadlock_sound`, plus corollaries `classicFreezeDeadlock_sound` and `block2x2Deadlock_sound`.

### 3.4 Decoupled Solver & Certificate Verification (`Sokoban/Solver.lean`)
Rather than proving full functional correctness of a BFS queue implementation, we use **certifying search**:
- `solveBFS` performs deadlock-pruned BFS up to `StateEquiv` (equality of player position and box set membership).
- On `.solved moves`, `verifySolution_sound` verifies `applyMoves` in linear time.
- On `.unsolvable visited`, `checkUnsolvableCert_sound` verifies in one pass over `visited` that:
  1. `s₀` is equivalent to an element of `visited`,
  2. no element of `visited` is solved, and
  3. every `execDir` successor of every element of `visited` either triggers `isSuperFreezeDeadlockWithLive` or maps into `visited` modulo `StateEquiv`.
- Soundness follows cleanly by induction on `Reach` using `StateEquiv.preserves_step`, `step_implies_execDir`, and `superFreezeDeadlockWithLive_sound`.

### 3.5 Formal Heuristic Refutations (`Sokoban/Counterexamples.lean`)
Three tempting heuristic optimizations are formalized and refuted constructively with `ValidState` + `heuristic = true` + `Solvable` + `isSuperFreezeDeadlock = false`:
1. `naiveDeadSquareFreeze_unsound`: checking `!live.contains` on the *pushing* side `step b d.opp` fails on `##### / #@$.# / #####`.
2. `naiveCurrentReachFreeze_unsound`: checking `CanWalkAvoiding` against *all* current boxes `s.boxes` instead of `F` fails on `cex2Board` (6×6, 4-move solution).
3. `naiveGoalLock_unsound`: locking `*` boxes on goals as permanent walls turns a 12-move solvable level (`cex3Board`, 7×4) into a provably unsolvable one.
