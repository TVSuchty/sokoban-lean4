## Highlights

1. **Unified Reachability-Aware Freeze Theorem (`superFreezeDeadlock_sound`):**
   Combines backward-BFS **Simple Dead Squares** (`computeLiveSquares`), iterative **Freeze Deadlocks** (`computeSuperFrozen`), and **topological player reachability** (`CanWalkAvoiding`) into one fixed-point deadlock detector, proving `¬ Solvable L s` whenever any non-goal box remains frozen.
2. **Three Tempting Heuristics Formally Refuted (`Sokoban/Counterexamples.lean`):**
   * `naiveDeadSquareFreeze_unsound`: Treating Simple Dead Squares like walls on the *pushing* side falsely flags `##### / #@$.# / #####` (solvable in 1 move).
   * `naiveCurrentReachFreeze_unsound`: Checking player walkability avoiding *all* current boxes instead of only frozen ones falsely flags a 4-move solvable 6×6 board.
   * `naiveGoalLock_unsound`: Refutes both locking boxes on goals (`*`) as walls and the weaker rule `StepNoOffGoalPush` (forbidding pushes from a goal onto non-goal floor) on an 8×4 board solvable in 14 moves.
3. **Certifying Solver & Standalone Checker (`Sokoban/Solver.lean`):**
   `solveBFS` prunes deadlocks via `isSuperFreezeDeadlockWithLive` and emits checkable witnesses (`.solved moves` or `.unsolvable (.initialDeadlock | .closedRegion visited)`). `checkUnsolvableCert` validates all structural premises (`ValidState`, `Nodup`, `ClosedPlayable`, membership) internally, and `verifySolveResult` unifies both outcomes.
